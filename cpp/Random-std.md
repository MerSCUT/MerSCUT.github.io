# `std::random` 库基本使用方法

C++中, 获取随机数可以用 `rand()` 这个方法, 但有许多劣势

- 模运算 导致分布不均匀
- 周期短
- 不可重入
- ...

而 `std::random` 是 C++ 引入的随机数库, 意在解决 `rand()` 的痛点. 总而言之, 这个库的设计与使用思路是 :

****引擎 + 分布****.

使用该库需要引入头文件 `#include<random>`.

## 引擎

这部分负责生成随机数序列, ****只在乎序列的随机性与概率均匀性****, 不在乎序列的取值范围和用途.

- 概率均匀性 : 落在随机数取值范围内每一个值的**概率**相同. 而不是在意生成出来的随机数列是否符合**值域空间上的均匀性, 不在意是否有明显的聚集点和空洞区域**.



常用的随机数生成引擎是 梅森旋转算法 (Mersense Twister), 以 `std::mt19937` 表示. 

```cpp
std::mt19937 gen(seed)
```

引擎对象 `gen()` 中的参数是**引擎初始化种子**. 同一个种子所产生的随机数序列是可复现的, 即程序多次运行结果相同. 若想获得完全随机的结果, 可以通过**硬件熵源 `std::random_device` 对象 ** 来获取随机种子.

```cpp
std::random_device rd;
unsigned int seed = rd();
```

初始化引擎后, 使用 引擎对象的 重载调用运算符 `operator()` 来获取随机数

```cpp
for(int i = 0; i < 10; i++)		// 生成10个随机数
{
std::cout <<  gen() << " ";		// 用 gen() 获取随机数
}
```



## 分布

这一部分会处理引擎不在意的部分 : ****随机数的分布, 范围(值域) ****.

下面是分布类的声明 :

```cpp
// [1,100] 上的均匀整数分布
std::uniform_int_distribution<> dis_int(1, 100);
// [1,100) 上的均匀浮点数分布
std::uniform_real_distribution<> dis_real(1,100);
```

接下来只需要将引擎对象传入分布的`operator()`即可获取需要的输出 :

```cpp
for(int i = 0; i < 10; i++)		// 生成10个随机数
{
std::cout <<  dis_int(gen) << " ";		/
}
```
