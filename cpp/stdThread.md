# 并发

可以与其他计算(函数)并行执行的计算(函数)称为**任务task**. 我们使用**线程**模型, 用一个**线程thread**来表示一个任务.

`std::thread` 是标准库中提供的线程库. 需要`#include<thread>`. 使用示例如下:

```C++
void f1();	// 定义略去
struct F{	// 函数类/结构
    void operator()(int x);		// 类F对象的调用运算符()
}

void user()
{
    // 主流程
    thread t1 {f1};
    thread t2 {F()};		// F() 调用构造函数创建了一个 F对象. 作为传入线程的参数, 默认是执行对象的()重载函数
    // 进程被创建以后就立刻开始并发执行了.
    t1.join();
    t2.join();
}
```

`t1.join()` 的含义是等待线程`t1`结束.

一旦 `t1`,`t2` 被初始化, `user`, `f1`, `F()()`之间就是并发执行的了.



# 互斥

有了并发自然离不开资源互斥的问题 : 多个线程同时访问一个资源时, 若不加以限制, 可能出现数据不一致的情况.

标准库提供了`mutex`类作为信号量, 来给互斥资源上锁, 任何线程在访问资源前需要先获得该资源的锁. 使用`mutex`需要`#include<mutex>`.

```C++
mutex m;		// 互斥量	
int share;		// 共享资源

void f()
{
    unique_lock<mutex> myLock {m};	// 获取 mutex 的锁, 内部会调用 m.lock();
    sh+= 7;
}	// 离开作用域时会隐式释放锁.
```

互斥量与共享资源通常有一一对应的关系, 所以组织成一个整体是更好的选择 :

```C++
class shareResource
{
  	mutex m;
    int share;
    // ...
};
```
