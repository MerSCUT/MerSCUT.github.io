# RTTI 机制 : 运行时类型识别

## `dynamic_cast`

内存布局 : (以 64 位系统和 GCC/Clang 为例)

- 在包含虚函数的类中有 `vptr` 成员, 指向 虚函数表 vtable **中的第一个虚函数**. 相对于 `vptr`, 负偏移区包含了其他的信息

  在 -16 字节偏移处, 存储的是**多继承中this指针偏移值**. 这里不多说.

  在 -8 字节偏移处则是本节的主角. `std::type_info*`

| **内存偏移 (Offset)** | **表项内容 (Content)** | **说明**                                              |
| --------------------- | ---------------------- | ----------------------------------------------------- |
| `-16` 字节            | `offset_to_top`        | 当前子对象指针相对于完整对象起始地址的偏移量          |
| `-8` 字节             | `typeinfo*`            | **指向当前类 `type_info` 结构体的指针 (RTTI 的核心)** |
| `0` 字节              | `vfunc[0]()`           | 第一个虚函数的地址 ( **`vptr` 实际上指向这里** )      |
| `+8` 字节             | `vfunc[1]()`           | 第二个虚函数的地址                                    |

`std::type_info` 结构体中包含 :

1. `.name()` : 返回类型名称, 通常是经过编码的字符串
2. `operator==` 和 `operator!=` 判断两个类型是否相同.

访问这个结构体需要使用关键字 : `typeid`. 

对一个基类指针`obj`所指向的对象使用该关键字,  `typeid(*obj)` 时, 编译器会在底层访问上述 `typeinfo` 结构体, 代码类似于 `*(obi->vptr-1);`.



基于`std::type_info` 最常见的应用就是 `dynamic_cast` 方法. 

该方法在**执行期工作**.

`dynamic_cast` 的最有价值的应用是, **在包含虚函数的类体系中, 让基类指针/引用安全地转换为派生类指针**. 

- **向上转换** : 派生类转为基类指针/引用, 此时**不需要检查类型.**
- **向下转换** : 安全性价值所在, 程序会检查该转换是否真的合法. 
  - **安全**体现在 : 若指针转换失败会返回 `nullptr`. 引用转换失败会返回 `std::bad_cast`.

使用方法为 : `Target* target_ptr = dynamic_cast<Target*>(base_ptr);`

```cpp
Base* ptr = new Derived();
// 尝试将 ptr 从 Base* -> Derived*
Derived* d_ptr = dynamic_cast<Derived*>(ptr);

if (d_ptr){
    // non-null
    cout << "转换成功" << endl;
}
else{
    cout << "转换失败" << endl;
}
```

具体, 判断**向下转换 DownCast** `dynamic<Target*>(ptr)`是否合法的逻辑如下 :

1. 访问 `ptr` 所指对象的虚函数表 `ptr->vptr`, 找到其 ` std::type_info`. 
2. 遍历继承树, 判断 `*ptr` 是否包含一个完整的 `Target` 子对象, 若是则允许转换. 
3. 补 : 在**多重继承中**, `type_info` 还会指导`dynamic_cast` 计算出(this)指针偏移量.



## `static_cast`

你可能听过与`dynamic_cast` 类似的 `static_cast` 方法. 

该方法运行在**编译期**, 且不要求有 RTTI 机制, 也就不要求类有虚函数.

它可以用来 :

1. **基本数据类型的安全转换**. 相比于 C-style 的 `(int)x`, 编译期会检查转换是否合法.
2. **类体系结构中的转换**. 但是不包含多态行为. 
   1. **向上转换** : 即使没有虚函数也可以进行.
   2. **向下转换** : `static_cast` 不会检查该转换是否正确.  基类的指针 `ptr` 即使没有指向一个派生类, 转换依然会发生.
3. **将`void*`指针转换为特定类型的指针**.

`static_cast` 是零开销的. 当转换失败时可能会编译报错, 也可能会带着逻辑错误执行程序.
