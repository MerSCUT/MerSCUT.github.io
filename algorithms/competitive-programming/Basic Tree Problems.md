# 4.7 简单树上问题

本节细致说明 **树**相关的内容.

__树是一种特殊的图 : 没有圈的连通图__. 一个树包含以下结构 或性质 :

- 树根
- 父节点 子节点关系唯一. 除了树根, **每个节点有且仅有一个父节点**
- __连通性__ : 从根出发能遍历整棵树.

从上述性质能推导出更多性质 : 

- 树有 $n$ 个节点, 有 $n-1$ 条边.
- 去掉一条边, 会分出两颗子树. 去掉一个结点, 会获得两颗以上的子树.
- 根出发到每一个结点, 都只有__唯一一条路径__.
- 任何两个结点之间添加一条边, 都会形成__圈__. 
  - (注意不是**环**, 有环的定义是存在从某点出发经过若干步不重复路径又回到该点.)

有向图会导出__有根树__, 仅有一个根结点. 

而基于无向图的树, 任何一个结点都可以成为树根, 称为__无根树__.



## 树的重心

也称为__树的质心__. 应用范围是__无根树__. 定义为 :

> 树的重心是这样一个节点 $u$ : 
>
> 无根树中, 取任意结点为根, 能够计算出该根的__最大子树的节点数__.
>
> 节点 $u$ 满足 : 在所有根中, 具有__最少的最大子树节点数__.

例如, 一个 $9$ 节点的树, 

- 删去节点 $v$ 后, 其它部分被分为节点数为 $3 + 3 + 2$ 的三颗子树. 此时 $v$ 的最大子树节点数为 $3$.
- 删去节点 $m$ 后, 被分成了 $2 + 2 + 2 + 2$ 的 四颗子树. $m$ 的最大子树节点树为 $2$.

以上述方式处理所有节点, 得到的最大子树节点数__最少的__ 就是 __树的重心__. 它表示__删去该节点后, 其他部分组成的子树在节点数语义下最为平衡__.

关于树的重心, 有以下重要结论 :

> 删去 $n$ 节点树的重心后, 剩余子树的节点数一定 $\leq$ $n/2$. 这同时意味着, __重心的最大子树节点数 $\leq n/2$__
>
> - 反证 : 倘若树 $T$ 删去某节点 $v$ 后, 有一颗子树 $T_1$ 的节点数  $a > n/2$, 显然它是最大子树节点数.
>
> - 易知其他子树的节点数总和为 $b < n/2$, 且满足 $a + b = n-1$.
>
>   设$T_1$ 子树与原有的节点 $v$ 相连的节点为 $m$.
>
>   那么删去 $m$ 后, 原来的 $T_1$ 所在的子树节点减少为 $\leq a-1$. 其他子树的节点和为 $b + 1$ (加入了 $v$)
>
>   下面讨论 : 
>
>   - 若 $a-1 \geq b+1$, 则说明 $m$ 的最大子树节点数为 $a-1 < a$, 证明 $v$ 不是重心.
>   - 若 $a - 1 < b+1$, 由 $a + b = n-1$ 得 $ b + 1 = n-a > a - 1$, 解得 $a < (n+1)/2$. 再由 $a > n/2$, $a$ 为整数得到矛盾. 不论 $n$ 是偶数还是奇数, $a$ 都无法取任何整数使得上面两个不等式成立.
>
>   得证.

另外, __一棵树的质心最多只有两个.__ 且当存在两个质心时, 两个质心中间必然有一条边相连.

这个结论在__树的分治__很有用.
