# 输入输出

```c++
#include <iostream>
#include <vector>
#include <string>
#include <numeric>
#include <algorithm>
using namespace std;

int main() {
    // 必写
    // 提速必备，打消 cin/cout 的性能劣势
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    // 常见输入类型 0: 一次程序中会有 T 个测试用例, 对每个用例再详细进行读取
    int T;
    cin >> T;
    while(T--){
        //... 对某一个测试用例单独处理 (注意, 这种写法不适合离线算法)
    }
	
    int n;
    // 常见输入类型 1：持续读取直到 EOF
    while (cin >> n) {
        // 处理逻辑
    }
    
    // 常见输入类型 2：读取包含空格的整行字符串
    string line;
    getline(cin, line); // 注意：如果前面用了 cin >>，这里前面需要额外加一个 getline(cin, temp) 吞掉换行符,  temp 是另一个变量.
    
    
    return 0;
}
```



#   线性容器 vector, string

` std::vector<T>` : 常用方法

- 末尾操作 : `v.push_back()`, `v.pop_back()`;
  - **请注意, 以下所有的容器在执行删除操作的时候, 都必须判断非空**
- 获取首尾元素 : `v.back()`, `v.front()`.
  - 这个用法在队列`queue` 中也成立.
- 中间插入/删除 (少用, 容易导致性能爆炸) : 
  - `v.insert(v.begin() + i, val)` : 
  - `v.erase(v.begin() + i)`;

`std::string` 常用方法 :

- 字符串拼接 : `string s = "Hello"; s += "World";`
- 尾部插入 与 尾部删除 : `s.push_back('!');`, `s.pop_back();`
- 获取子串, 经典的(起始索引 + 长度)的组合. : `s.substr(start_index, length)` 
  - **可以省略 `length`不写, 默认截取到字符串尾部.**
- 数值类型(包括int, float 等) 转 string, 返回 string 值. : `to_string(integer)` 
- string 转 int / long long, 返回后者的值 : `stoi(s)` / `stoll(s)` 
  - 同理还有 `stof("0.99")`, string 转 float : `0.99f` .
- 寻找子串, 返回索引 : `s.find("abc")`
  - ==若没有找到则返回 `string::npos`==

# O(1)查询容器

哈希表 `std::unordered_map<keyType, valueType> hash` 常用方法 :

- 插入/更新 : `hash[key] = value;`

  - 注 : 只要访问 `hash[key]`, 即使表中原来没有 `key` 的值, 或者没有指定`value` 也会创建.

- 判断key是否存在 : `hash.count(key);`, 返回 0 或 1

- 删除键值对 : `hash.erase(key)`;

- 安全查找 : 

  ```cpp
  if (m.find(key) != m.end()) {
      // 找到了，m.find(key)->second 是 value
  }
  ```

- 遍历 :

  ```cpp
  for (auto& [k, v] : m) {
      // C++17 结构化绑定，直接使用 k 和 v
  }
  ```

  



集合 `std::unordered_set<Type> set` 的用法与哈希表类似, 相当于只有 key 没有 value. 

> 注意, 二者的 "unordered" 已经暗示了其中元素的无序性.



# 优先队列 / 堆

`priority_queue<int> pq` : 

- 上述构造方法**默认是大根堆**, 即寻找最大值.
  - 构造小根堆用 `priority_queue<int, vector<int>, greater<int>> pq;`
- 常用方法 :
  1. 入队 `pq.push(element);`
  2. 出队最大元素 `pq.pop()`;
  3. 获取最大元素 `pq.top()`;
  4. 判断队列是否为空 `pq.empty()`.
  5. 返回元素个数 `pq.size()`;

# 有序关联容器

指的是 `set`, `multiset`, `map` . 它们的底层实现都是**红黑树**, 这保证了它们的**内部元素有序性**.

- `set` 是有序的集合 (对比起 `unordered_set`.) 
  - **使用场景** : 随时获取动态数据的**最大/最小值**, 且需要**数据不重复**.
- `multiset` : 与 `set` 仅有的区别是**允许元素重复**.
- `map` : 与 `set` 类似, 但是存储的元素是**键值对**. 有序性是对于 key 说的.



# 算法库 `<algorithm>`

注意需要在 std 命名空间, 且需要引入 `<algorithm> ` 库. 有些是 `<numeric>` 库.

## 排序

- `sort` : 排序神器. 复杂度 $O(n\log n)$. `sort` 中的三个参数表示
  - 起始位置
  - 终止位置的下一个位置
  - 排序规则 (可用Lambda函数自定义或重载)

## 二分查找

- `lower_bound(...) `/ `upper_bound(...)` : **二分查找算法**.

  - 参数 : `(v.begin(), v.end(), targetValue)`;

  - **使用前需要先对容器排序! 默认需要升序排列**

    - 如果想对降序排列的容器进行, 则需要**添加第四个参数** : `(start, end, target, greater<int>)` (这里假设是对 `vector<int>` 降序排列的元素进行二分查找, 所以使用`int`的大于函数`greater<int>`)

  - 两个都是二分查找, 但是实现上略有不同. 假设 `std::vector<int> v` 是一个升序排列的数组. `v` 中有许多相同的值 `4`, 在查找 `v` 中的元素 `targetValue = 4` 时 :

    - `lower_bound()` 会返回第一个 $\geq $ $4$ 的元素;
    - `upper_bound()` 会返回第一个 $>4$ 的元素.

  - **两个函数返回的都是迭代器** : 为了获得我们更熟悉的**索引**, 只需要

    ```c++
    int idx = lower_bound(v.begin(), v.end(), 4) - v.begin();
    ```

- `max_element(v.begin(), v.end());` : 返回指向 `v` 的最大值的迭代器. 要获得最大值需要加`*`号解引用

- `accumulate(v.begin(), v.end(),0LL)` : 求和. `0LL` 是为了防止`int`溢出.

----

## Lambda 表达式 + sort

```cpp
sort(v.begin(), v.end(), [](const myStruct a, const myStruct b){
	// Lambda 函数体, 指明的是判断 a < b 为 true 时的定义.
	return a.height < b.height;
})
```

请务必不要写成 `a <= b`  的定义.

## 有序容器中某元素的出现次数

设已经升序排列的容器为 `vector<int> v;`, 此时要查找 `v` 中出现了多少次元素 `int t = 5;`, 一个一行代码能解决的方法是 :

```cpp
int num = upper_bound(v.begin(), v.end(), t) - lower_bound(v.begin(), v.end(), t);
```



## 关于字典序问题

标准库中包含 `next_permutation("abc")` 函数, 返回输入字符串的下一个字典序的值.

可以以 $O(n!)$ 的复杂度暴力解决一些小规模的字典序问题.

倘若想进一步优化,  一般是通过组合数学的方法来进行.

- 例如对于 `abc` 组成的任意字符串, 返回第 $K = 4$ 字典序的字符串.
  - 这个问题中, 利用组合数学的知识很容易算得 `a` 开头的字符串只有 2 个, 接下来问题转化为 $K = K - 2$, 然后对 `bc` 去进行讨论.  



# STL 常用容器整合

## 序列容器


| **C++ 名称**  | **实际数据结构**          | **核心性质与时间复杂度**                                     |
| ------------- | ------------------------- | ------------------------------------------------------------ |
| `std::vector` | 动态连续数组              | **性质**：内存连续，空间不够时通常按 1.5 倍或 2 倍扩容并整体搬移。 **复杂度**：支持 $O(1)$ 随机访问；尾部插入/删除均摊 $O(1)$；中间插入/删除 $O(N)$。 **注意**：具有极高的 CPU 缓存命中率，是绝大多数情况下的首选容器。 |
| `std::deque`  | 分段连续数组 (数组的数组) | **性质**：由固定大小的数组块（通常是指针数组）拼接而成，两端均可开口。 **复杂度**：支持 $O(1)$ 随机访问；头尾插入/删除均为 $O(1)$。 **注意**：内部寻址逻辑比 `vector` 复杂，常数开销略大。 |
| `std::list`   | 双向链表                  | **性质**：内存不连续，节点间通过指针连接。 **复杂度**：不支持随机访问，按索引查找为 $O(N)$；但在已知节点迭代器的情况下，插入和删除操作均为 $O(1)$。 |
| `std::string` | 字符动态数组              | **性质**：专为字符设计的 `vector`，现代 C++ 通常实现了短字符串优化 (SSO)，即短字符串直接存在栈上，不分配堆内存。 |

## 有序关联容器

| **C++ 名称**    | **实际数据结构**          | **核心性质与时间复杂度**                                     |
| --------------- | ------------------------- | ------------------------------------------------------------ |
| `std::set`      | 红黑树 (自平衡二叉搜索树) | **性质**：元素自动按升序排列，且集合内元素唯一。 **复杂度**：查找、插入、删除的严格最坏时间复杂度均为 $O(\log N)$。 |
| `std::multiset` | 红黑树                    | **性质**：与 `set` 类似，但允许插入重复的元素。常用于需要动态维护有序序列（包括重复值）的场景。 |
| `std::map`      | 红黑树                    | **性质**：存储键值对 (Key-Value)，按 Key 自动排序，Key 是唯一的。 **复杂度**：基于 Key 的查找、插入、删除均为 $O(\log N)$。 |

## 无序关联容器

| **C++ 名称**         | **实际数据结构**              | **核心性质与时间复杂度**                                     |
| -------------------- | ----------------------------- | ------------------------------------------------------------ |
| `std::unordered_set` | 哈希表 (通常用拉链法解决冲突) | **性质**：元素无序，依靠哈希函数映射存储位置，元素唯一。 **复杂度**：平均查找、插入、删除复杂度均为 $O(1)$；但如果哈希冲突严重，最坏情况会退化到 $O(N)$。 |
| `std::unordered_map` | 哈希表                        | **性质**：无序的键值对存储。同样依赖哈希函数的质量。 **复杂度**：平均 $O(1)$ 增删查改。 **注意**：对于自定义类型作为 Key，必须手动提供哈希函数 (`std::hash`) 和相等比较操作符 (`operator==`)。 |

## 操作限制容器

| **C++ 名称**          | **实际数据结构**                                     | **核心性质与时间复杂度**                                     |
| --------------------- | ---------------------------------------------------- | ------------------------------------------------------------ |
| `std::stack`          | 默认基于 `std::deque`                                | **性质**：后进先出 (LIFO) 结构，封闭了一端。 **复杂度**：压栈 (`push`)、弹栈 (`pop`)、获取栈顶 (`top`) 均为 $O(1)$。 |
| `std::queue`          | 默认基于 `std::deque`                                | **性质**：先进先出 (FIFO) 结构。 **复杂度**：入队 (`push`)、出队 (`pop`)、获取队头 (`front`) 均为 $O(1)$。 |
| `std::priority_queue` | 堆 (Heap)，默认是基于 `std::vector` 构建的**大根堆** | **性质**：能够动态维护集合中的最值。内部使用 `std::make_heap`, `std::push_heap` 等算法维护结构。 **复杂度**：获取最值 (`top`) 为 $O(1)$；插入元素 (`push`) 和弹出最值 (`pop`) 为 $O(\log N)$。 |
