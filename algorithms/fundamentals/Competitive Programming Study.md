# 5. DP 动态规划

## 5.2 经典线性 DP

1. 分组背包 : 物品被分为几组, __每组只能选一个__.
   1. 解法 : 没啥好方法, 三重循环 DP. 用自我滚动进行优化
2. 多重背包 : 物品 $i$ 最多可以被选择 $m_i$ 次. 
   1. 解法 : 看成有 $m_i$ 个独立物品按照经典01背包做, 直接三重循环能解, 效率低. 
   2. __二进制优化__是一个简单而有效的优化 : 假设 $m_i = 25$, 不将问题转化为 25 个 $i$ 物体求解, 而是利用二进制转化为 $25 = 16 + 8 + 1$, 然后将物品 $i$ 拆分为 3 个物体, 每个物体分别是 $16$ 个$i$, $8$个$i$, $1$ 个 $i$.
   3. __单调队列__ : 5.8节讲, 是本问题最优解.
3. __最长公共子序列问题__ : 子序列是指序列删去若干元素后得到的序列. 求序列 $X$, $Y$ 的最长公共子序列 $Z$.
   1. DP 法 : 设状态 `dp[i][j]`表示 $X$ 的前 $i$ 和 $Y$ 的前 $j$ 序列的最长公共子序列长度. 状态转移方法
