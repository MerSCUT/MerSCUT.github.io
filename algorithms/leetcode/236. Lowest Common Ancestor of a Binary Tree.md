# 236. 二叉树最近公共祖先

这题的思考量不小.

核心在于如何找到一个**唯一准则, 判断某个结点是否为公共祖先**.

本题用到了一个很巧, 不一定能立刻想到的思路. 利用递归, 在结点之间传递的信息是 **当前结点的子树是否包含 p ==或== q**. 若是则为 `true`.

第一波思路就是使用 DFS 来传递这个信息, 找到第一个满足以下条件的结点 $x$ :

- $x$ 的左子结点和右子结点都返回 `true`.
  - 说明一个在 $x$ 左侧, 另一个在 $x$ 右侧. $x$ 就是公共祖先. 此时对应p与q没有包含关系.
- $x$ 本身是 $p$ 或 $q$, 同时 $x$ 的左节点或右节点之一返回了 `true`.
  - $x$ 可以是 $x$ 自己的祖先. 这种情况下, 说明 $p$ 和 $q$ 有包含关系.

这种方法已经可以做出该题.

```C++
class Solution {
public:
    TreeNode* ans;
    bool dfs(TreeNode* root, TreeNode* p, TreeNode* q)
    {
        if (!root) return false;
        bool rt = (root == p || root == q);
        bool lson = dfs(root->left, p, q);
        bool rson = dfs(root->right, p, q);
        if (lson && rson) ans = root;
        if (lson && !rson) {
            if (root == p || root == q) ans = root;
        }
        
        if (!lson && rson) {
            if (root == p || root == q) ans = root;
        }
        return lson || rson || rt;
    }
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        ans = root;
        dfs(root,p,q);
        return ans;
    }
};
```

还有另一种思路. 首先上述代码中利用一个递归函数`dfs`和全局变量`ans`保存遍历过程的答案.

但是返回值是 `bool` 的话, 为什么不考虑用题目本身的函数 `lowestCommonAncestor` 返回值是否为`nullptr`来代替`bool`呢?

并且为了保证该接口最终是返回 `ans` 的, 我们需要在 非`nullptr`时, 返回最小的公共祖先.



上述判断条件还能进行修改 :

- $x$ 的两侧结点返回值都非空时, 说明 $x$ 就是祖先, 直接返回 $x$.
- (代替上面第二种) : 当 $p$ 和 $q$ 有包含关系时, 不妨设 $p$ 是祖先. **倘若遍历过程中, 遇到 $p$ 就返回, 不再往下走**, 那么前面的祖先不会再遇到任何能成立最小公共祖先条件的情况. 此时之前遇到的 $p$ 就是最小公共祖先.

代码会十分简洁. 思路来自 Gemini.

```C++
class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        if (!root) return nullptr;
        if (root == p || root == q) return root;
        TreeNode* lson = lowestCommonAncestor(root->left, p, q);
        TreeNode* rson = lowestCommonAncestor(root->right, p, q);
        if (lson && rson){
            return root;
        }
        // 此时 lson 和 rson 没有同时为 true. 若二者都是 nullptr 则也返回nullptr.
        // 若有其中一个是true, 下面的方式会返回那个 true 的结点.该代码是一种极其简洁的写法. 
        return lson ? lson : rson;
    }
};  
```
