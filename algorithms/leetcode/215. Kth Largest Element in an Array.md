## 215. 数组 topK 大元素

经典必做题.

第一想法是排序后直接取下标 $k-1$ 即可.

```C++
int findKthLargest(vector<int>& nums, int k) {
    sort(nums.begin(), nums.end(), greater<int>());
    return nums[k-1];
}
```

但题目要求 $O(n)$ 的时间复杂度, 这种做法明显超标. 

上述算法可优化的部分在于, 我们只需要数组的第 $k$ 大, 而不需要**将整个数组排序 (全量排序)**. 

`sort`函数底层实现是快排, 快排会选中一个元素 `pivot`, 将大于它的放在一侧, 小于它的放在另一侧. 这也意味着, 选中的 `pivot` 可以在一次划分中确定下标索引.

我们可以借助快排的思路, 既然我们只需要找索引为 `k-1` 的元素, 我们没有必要像快排那样, 在分划完后对`pivot`两侧的数组递归快排.

如果发现`pivot`的下标刚好就是 `k-1`, 就可以直接返回结果了.

若 `< k-1` , 那就对 `pivot` 右侧的子数组快排; `>k-1` 就对左侧快排. 

这样避免了快速选择的全量排序, 这种方法称为**快速选择**. **复杂度为 $O(n)$.**

```C++
class Solution {
public:
    int findKthLargest(vector<int>& nums, int k) {
        // 定制快排
        return nums[quickSort(nums, k, 0, nums.size()-1)];
    }

    int quickSort(vector<int>&nums, int k, int low, int high){
        if (low <= high){
            int pivot = partition(nums, low, high);
            if (pivot == k-1) return pivot; 
            if (pivot < k-1) {
                return quickSort(nums, k, pivot + 1, high);
            }
            if (pivot > k-1){
                return quickSort(nums, k, low, pivot - 1);
            }
        }
        return -1;
    }
    int partition(vector<int>&nums, int low, int high){
        // 选择区间中点
        int randomIndex = (low + high) /2;
        swap(nums[low], nums[randomIndex]);

        int pivot = nums[low];
        // 随机选取基准值
        while(low < high){
            while(low < high && nums[high] <= pivot) high--;
            nums[low] = nums[high];
            while(low < high && nums[low] >= pivot) low++;
            nums[high] = nums[low];
        }
        nums[low] = pivot;
        return low;
    }
};
```

该代码的运行时间很长. 快选的逻辑是没问题的. 题解中提到**对于Leetcode中生成的数据可能复杂度偏高**.

上述代码的主要开销来源于 

- `quickSort` 递归调用的压栈开销.
- `nums` 中重复元素过多时, 复杂度会退化为 $O(N^2)$. 

代码中的 `partition` 修改为以下写法 : (双指针 Hoare 变体)

```C++
int partition(vector<int>& nums, int low, int high) {
    int randomIndex = low + rand() % (high - low + 1);
    int pivot = nums[randomIndex];
    swap(nums[low], nums[randomIndex]); // 把 pivot 藏在左边

    int i = low + 1, j = high;
    while (true) {
        while (i <= j && nums[i] > pivot) i++; // 寻找比 pivot 小的
        while (i <= j && nums[j] < pivot) j--; // 寻找比 pivot 大的
        if (i >= j) break;
        swap(nums[i++], nums[j--]);
    }
    swap(nums[low], nums[j]); // 把 pivot 放回中间
    // 可以思考为什么是 j 而不是 i. 这与函数开始时把随机选择的 pivot 放到了数组开头有关.
    return j;
}
```

这种写法的逻辑是 : `i` 和 `j` 总是往一侧扫描, 直到**遇到第一个绝对不应该在左/右**边的元素.

它们都停下时, 才进行一次 `swap`. 

相比于前一种写法, 这种方法能较快处理**重复元素较多的数据**. 

假设 `pivot = 5`, 此时若`nums` 中也包含许多个连续的 `5`, 例如 `{1, 7, 4, 5, 5, 5, 2, 9}`. 

双指针写法在处理这种数据时, `i` 会停在第一个 `5`, `j` 会停在最后一个 `5`. 然后进行一次 `swap` 后再次**齐头并进**. 这导致它们在相遇时, 相遇点一定在连续`5` 的**中间**. 

而前一种写法的 `pivot` 会停靠在最左侧/最右侧的 `5`. 下一步递归时仍然面临处理许多`5` 的风险.

注意两种写法在代码上边界条件处理的细微区别.

----

除了快速选择以外, 还可以利用**堆排序**进行. 堆排序的过程是**不断找到未排序部分的最大/最小元素并归入已排序区域中**. 当 $k$ 较小时, 算法有十分优秀的效果.

```C++
class Solution {
public:
    // 大根堆
    void max_heapify(vector<int>& nums, int root, int end) {
        int par = root;
        int son = par * 2 + 1;
        while (son <= end) {
            if (son < end && nums[son + 1] > nums[son])
                son++;
            if (nums[par] >= nums[son])     
                return;
            swap(nums[par], nums[son]);
            par = son;
            son = par * 2 + 1;
        }
        return;
    }
    int findKthLargest(vector<int>& nums, int k) {
        // 建堆 (注 : 从 0 开始的下标, 其最后的非叶结点)
        int end = nums.size() - 1;
        for (int i = (end - 1) / 2 ; i >= 0; i--) {
            max_heapify(nums, i, end);
        }
        // 排序 (注意边界的计算)
        for (int e = end; end - e < k; e--) {
            swap(nums[0], nums[e]); 		// 倒数第 K 个.
            max_heapify(nums, 0, e - 1);
        }
        return nums[end - k + 1];
    }
};
```

时间复杂度为 $O(N + K\log N)$.

另一种实际应用性更强的方法是 : 维持堆中仅有 $K$ 个元素. 这种方法可以不必将所有数据都放入内存中.

1. 先将前 $k$ 个元素建**小根堆**.  (注意虽然求的是Topk, 但用的不是大根堆)
2. 不断扫描 其他数据, 与堆顶作比较. 若比堆顶大则用当前元素覆写堆顶, 并进行堆管理.

最后, 只需要取堆顶元素即可. 复杂度为 $O(N\log K)$.

```C++
class Solution {
public:
    void min_heapify(vector<int>& nums, int root, int end) {
        int par = root;
        int son = par * 2 + 1;
        while (son <= end) {
            if (son < end && nums[son + 1] < nums[son])
                son++;
            if (nums[par] <= nums[son])     
                return;
            swap(nums[par], nums[son]);
            par = son;
            son = par * 2 + 1;
        }
        return;
    }

    int findKthLargest(vector<int>& nums, int k) {
        vector<int> frontK(nums.begin(), nums.begin() + k);
        int end = frontK.size() - 1;
        // 前 k 个元素建堆
        for(int i = (end - 1)/2; i >= 0; i-- ){
            min_heapify(frontK, i, end);
        }
        // 扫描
        for(int j = k; j < nums.size(); j++){
            if (nums[j] > frontK[0]){
                frontK[0] = nums[j];
                min_heapify(frontK, 0, end);
            }
        }
        return frontK[0];
    }
};
```
